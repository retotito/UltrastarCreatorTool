# Keyboard Shortcuts

> **Status:** Current · **Last updated:** 2026-10-25

## Find

| Shortcut | Action |
|----------|--------|
| **Ctrl/Cmd+F** | Find a syllable (also the 🔍 button at the top right); **Esc** closes it |

## Selection

| Shortcut | Action |
|----------|--------|
| **Click** | Select single note |
| **Ctrl/Cmd+Click** | Toggle note into/out of multi-selection |
| **Ctrl/Cmd+Drag** | Rubber-band box select (select all notes in a rectangle) |
| **Ctrl/Cmd+A** | Select all notes |
| **Tab** | Select next note (single selection only) |
| **Shift+Tab** | Select previous note (single selection only) |

## Extension & Boundaries (new!)

| Shortcut | Action |
|----------|--------|
| **Option+→** | Extend selection to next touching note |
| **Option+←** | Extend selection to previous touching note |
| **Shift+Option+→** | Move shared boundary right (when 2 touching notes selected) |
| **Shift+Option+←** | Move shared boundary left (when 2 touching notes selected) |

## Editing

| Shortcut | Action |
|----------|--------|
| **Drag** | Move note(s) |
| **Shift+Drag** | Move note(s) horizontally only (lock pitch) |
| **←/→** | Move selected note ±1 beat (seek ±5s if no selection) |
| **Shift+←/→** | Move selected note ±4 beats (seek ±1s if no selection) |
| **↑** | Shift pitch +1 semitone |
| **↓** | Shift pitch -1 semitone |
| **Shift+↑** | Shift pitch +1 octave |
| **Shift+↓** | Shift pitch -1 octave |
| **Ctrl/Cmd+←/→** | Resize right edge (duration) - single note only |
| **Ctrl/Cmd+Shift+←/→** | Resize left edge (startBeat) - single note only |

## Note Actions

| Shortcut | Action |
|----------|--------|
| **Delete / Backspace** | Delete selected note(s) |
| **S** | Split note (context menu open) |
| **J** | Merge with next note (context menu open) |
| **Shift+J** | Merge with previous note (context menu open) |
| **P** | Play note pitch (context menu open) |

## Clipboard & Undo/Redo

| Shortcut | Action |
|----------|--------|
| **Ctrl/Cmd+X** | Cut selected notes |
| **Ctrl/Cmd+C** | Copy selected notes |
| **Ctrl/Cmd+V** | Paste notes (enters preview mode) |
| **Ctrl/Cmd+Z** | Undo |
| **Ctrl/Cmd+Shift+Z** | Redo |
| **Ctrl/Cmd+S** | Force save |

## Tools & Modes

| Shortcut | Action |
|----------|--------|
| **Ctrl/Cmd+B** | Grid Align mode (align grid to music) |
| **Ctrl/Cmd+G** | Set GAP mode (pick which grid line is beat 0) |
| **Space** | Play/pause playback |
| **L** | Toggle loop on/off |
| **M** | Toggle mic sing-along |
| **9** | Toggle MIDI playback |
| **0** | Toggle metronome |
| **Escape** | Cancel operation, clear selection, or clear loop |

## During Playback

| Shortcut | Action |
|----------|--------|
| **Space** | Play/pause |
| **←** | Seek backward 5 seconds (1 second with Shift) |
| **→** | Seek forward 5 seconds (1 second with Shift) |
| **L** | Toggle loop |
| **M** | Toggle mic |
| **Escape** | Clear loop |
